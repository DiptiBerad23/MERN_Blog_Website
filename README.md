# 📝 MERN Stack Blogging Platform

A full-stack **Blogging Platform** developed using the **MERN Stack** as part of a **45 Days Web Development Internship** at **Scalefull Technologies, Pune**.

This application allows users to **Create, Read, Update, and Delete (CRUD)** blog posts through a dynamic and responsive web interface.

---

## 🚀 Project Overview

- **Project Title:** Blogging Platform
- **Internship Duration:** 45 Days
- **Organization:** Scalefull Technologies, Pune
- **Project Type:** Full Stack Web Application
- **Architecture:** MERN Stack

## ✨ Features

- Create new blog posts
- Read and view blogs dynamically
- Update existing blog content
- Delete blog posts
- RESTful API integration
- Responsive UI
- CRUD operations using MongoDB
